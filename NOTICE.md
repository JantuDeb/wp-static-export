## Bundled third-party code

PHP libraries in `vendor-prefixed/` (namespaced under `WP_Static_Export\Vendor` so they cannot clash with other plugins):

- matthiasmullie/minify and matthiasmullie/path-converter, MIT licence: CSS and JavaScript minification.
- phpseclib/phpseclib, MIT licence, with paragonie/constant_time_encoding, MIT licence: SFTP.

Each library's licence file is kept next to its code. The BLAKE3 hash in `src/engine/blake3.php` is generated by
`scripts/gen-blake3.py` from the public-domain BLAKE3 specification and checked against the reference implementation.
